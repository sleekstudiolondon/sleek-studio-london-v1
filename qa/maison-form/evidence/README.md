# Maison Form QA Evidence

This directory is review evidence only and is not served from the production runtime.

- `desktop-reference-comparison/desktop-reference-report.md` contains the final per-reference visual comparison table.
- `desktop-reference-comparison/generated/` contains the Playwright screenshots.
- `desktop-reference-comparison/reference/` contains the canonical reference copies used for QA.
- `desktop-reference-comparison/diff/` contains the final diff images.
- `screenshot-matrix/screenshot-manifest.json` lists the responsive screenshot matrix.
- `responsive-width-checks/1280x900/` and `responsive-width-checks/360x800/` contain the exact-width verification screenshots and reports.
